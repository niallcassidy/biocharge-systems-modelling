# Biocharge Systems Modelling

An n-of-1 study using my own wearable data (February to October 2026) to reverse engineer the formula behind the Zepp daily Biocharge score, and to explore the structure and dynamics of the underlying physiology.

## Aims

The project is organised in phases, so that a complete result exists after Phase 2 and later phases are extensions.

**Phase 1: Reverse engineer Biocharge**
- Clean and merge the Zepp exports into one daily dataset.
- Fit regression models with same-day and lagged predictors (sleep, HRV, resting heart rate, stress, activity).
- Benchmark against machine learning models: penalised regression (ridge, lasso, elastic net), random forest and gradient boosting.
- Use variable importance and partial dependence plots to identify what drives the score.
- Evaluate on held-out data using time-ordered splits (fit on earlier months, test on later months).

**Phase 2: Composite measures**
- Build composites using Principal Components Analysis (PCA).
- Compare PCA with factor analysis and discuss when each is appropriate.

**Phase 3: Dynamics over time**
- Time-series analysis (trend, seasonality, autocorrelation).
- State-space models.
- Hidden Markov models (2 to 3 latent states, e.g. recovered, strained, ill).

**Phase 4 (exploratory): Non-linear methods and theory**
- Non-linear time-series methods and chaos analysis (e.g. attractor reconstruction, Lyapunov exponents), treated as exploratory because the series is short and noisy.
- Interpretation through general systems theory and cybernetics (feedback, homeostasis, regulation).
- Possible extension: a small neural network compared against simpler models.

## Data

- **Source:** Amazfit Helio Strap, synced through the Zepp app. Data were exported from Zepp and imported for analysis.
- **Period:** February 2026 to October 2026, daily resolution.
- **Raw data:** personal health data, so it is **not stored in this repository**. Place exported files in `data/raw/` to run the analysis.
- **Synthetic data:** `data/synthetic/` holds simulated data with a similar structure so the code can be run without my real data. It is generated by `R/[script-name].R`.
- **Data dictionary:** variable definitions are in `documentation/`.

## How to run

1. Clone this repository and open the project in RStudio.
2. Install the required packages (see below).
3. Add the Zepp export to `data/raw/` (or use the synthetic data).
4. Run the scripts in `R/` in order, starting with `01_clean_data.R`.
5. Open the documents in `analysis/` and render them.

## Limitations

- **Single participant (n = 1):** findings describe me, not people in general.
- **Small sample:** roughly 300 daily observations limit model complexity. This is why I favour interpretable models and use deep learning only as an optional extension.
- **Proprietary score:** Biocharge is calculated by Zepp, so any recovered formula is an approximation, and some inputs may not be exported.
- **Autocorrelation:** neighbouring days are not independent, so I use time-ordered validation rather than random splits.
- **Chaos analysis:** short, noisy physiological series are not well suited to Lyapunov-type methods, so those results are exploratory.
